# عاصفة الجنرالات — Storm Generals

النسخة التجريبية التأسيسية 0.1.0 للهواتف، مبنية بمحرك Godot 4.4.1.

## المحتويات الحالية
- اختيار أربعة جيوش: الأمريكي، الصيني، الجيش العربي، وطن.
- قاعدة اللاعب وقاعدة خصم تجريبي.
- إنتاج المشاة والدبابات مقابل الموارد.
- تحديد الوحدات باللمس أو السحب وإصدار أوامر الحركة.
- خصم أولي ينتج وحدات ويتقدم نحو قاعدة اللاعب.

## بناء Android
يعمل GitHub Actions عند كل تحديث على فرع main أو عند تشغيل سير العمل يدوياً. يتولى سير العمل تنزيل قوالب تصدير Godot وإعداد توقيع debug ثم إنشاء APK ورفعه كـ Artifact.

بعد نجاح البناء، افتح Actions ثم أحدث تشغيل ناجح، ونزّل Artifact باسم StormGenerals-Android-APK.

هذه نسخة أولية قابلة للتطوير، وليست بعدُ لعبة مكتملة أو متوازنة.
