# عاصفة الجنرالات — Storm Generals

تحديث التطوير 0.2.0 للهواتف، مبنية بمحرك Godot 4.4.1.

## المحتويات الحالية
- اختيار أربعة جيوش: الأمريكي، الصيني، الجيش العربي، وطن.
- قاعدة اللاعب وقاعدة خصم تجريبي.
- إنتاج المشاة والدبابات مقابل الموارد.
- اقتصاد أولي بدخل موارد تلقائي مع حد أقصى للرصيد.
- بناء الثكنات والمصانع في مواقع يحددها اللاعب داخل منطقته، مقابل الموارد.
- تتطلب صناعة المشاة وجود ثكنة، وتتطلب صناعة الدبابات وجود مصنع.
- أبراج دفاعية قابلة للبناء تطلق تلقائياً على وحدات العدو ضمن مداها.
- تحديد الوحدات باللمس أو السحب وإصدار أوامر الحركة.
- إصدار أمر هجوم عند تحديد وحدات اللاعب ثم لمس وحدة العدو.
- اشتباك تلقائي ضمن مدى السلاح، مع تبادل الضرر بين قوات اللاعب والعدو.
- خصم أولي ينتج وحدات ويتقدم نحو قاعدة اللاعب.

## خطة إصدار Android
تم تأجيل إنشاء APK عمداً إلى ما بعد اكتمال أنظمة اللعب، واختبارات الجودة، ومراجعة توازن الجيوش وتجربة العرض على الهاتف. سير عمل Android محفوظ للتشغيل اليدوي فقط عند اتخاذ قرار الإصدار التجريبي؛ لن يبدأ تلقائياً مع كل تحديث للعبة.

هذه نسخة تطويرية قيد البناء، وليست بعدُ إصداراً جاهزاً للاعبين.
