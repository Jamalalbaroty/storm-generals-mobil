# عاصفة الجنرالات — Storm Generals

تحديث التطوير **0.3.0** للهواتف، مبني بمحرك Godot 4.4.1. المشروع في مرحلة تطوير واختبار، وليس إصداراً نهائياً.

## الجيوش
- الأمريكي: قوات متوازنة متعددة المهام.
- الصيني: كفاءة أعلى في إنتاج بعض الوحدات المدرعة والبحرية.
- الجيش العربي: مشاة ومدفعية اقتصادية.
- وطن: وحدات نخبة قوية بتكلفة إنتاج أعلى للحفاظ على التوازن.

## أنظمة اللعب الحالية
- اختيار أربعة جيوش، مع قواعد اللاعب والخصم واقتصاد ونقاط إمداد.
- بناء الثكنات والمصانع والمطارات والمنشآت الدفاعية والبحرية وفق متطلبات البناء.
- إنتاج وحدات برية وجوية وبحرية وصواريخ عبر قوائم إنتاج وتكاليف موارد وإمدادات.
- لوحة أوامر هاتفية بأربعة تبويبات: البرية، الجوية، الاستراتيجية، والبحرية، تغطي 23 إجراءً.
- تحديد الوحدات باللمس أو السحب، وإصدار أوامر الحركة والهجوم.
- اشتباك تلقائي، دفاعات وأهداف استراتيجية، وخصم يستخدم إنتاجاً وتكتيكات واستجابات للتهديدات.
- تحسين تشكيلات حركة الوحدات وتنظيف التحديد والأهداف عند تدمير الوحدات.
- استرداد جزء من الموارد عند إلغاء الإنتاج بسبب تدمير المنشأة المنتجة.
- ساحة ثلاثية الأبعاد تجريبية وجسر لمزامنة وحدات اللعب معها؛ ما زال مشهد اللعب الأساسي ثنائي الأبعاد، ولا تُعد النماذج ثلاثية الأبعاد الحالية أصولاً نهائية.

## الجودة والبناء
- اختبارات Godot آلية للاقتصاد والإنتاج وسلوك الخصم والمدفعية والجسر بين اللعب ثنائي وثلاثي الأبعاد.
- سير عمل التحقق يعمل على تحديثات الفرع الرئيسي.
- بعد نجاح اختبارات Regression على الفرع الرئيسي، يُبنى مرشح Android تجريبي تلقائياً ويُرفع كـ GitHub Actions artifact؛ كما يمكن تشغيل التصدير يدوياً.
- تم بناء APK تجريبي والتحقق آلياً من سلامة الحزمة والتوقيع ومعمارية ARM64؛ لم يُؤكد تشغيله على هاتف Android فعلي بعد، ولا يُعد إصداراً نهائياً.

## حالة المشروع
هذه نسخة تطويرية قيد البناء. ما زالت هناك حاجة إلى اختبار متكامل للمباريات، ومراجعة توازن الجيوش، والتحقق من الأداء وسهولة التحكم على الهاتف، واستكمال نقل العرض إلى ثلاثي الأبعاد قبل اعتبارها إصداراً نهائياً.
